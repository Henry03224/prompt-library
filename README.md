## Quick start

1. Open a file in `prompts/`.
2. Copy the block under **Prompt**.
3. Replace placeholders like `[LANGUAGE]` or `[CODE]`.
4. Paste into your AI.

## Prompt anatomy

A strong prompt has five parts:

1. **Role** — who the model is (`You are a senior TypeScript reviewer`)
2. **Task** — the one job to do
3. **Context** — code, audience, constraints, examples
4. **Format** — how the answer should look (list, table, diff, JSON)
5. **Quality bar** — what to avoid and what "done" means

See [`guides/how-to-prompt.md`](guides/how-to-prompt.md) for the full playbook.
