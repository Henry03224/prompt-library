# Contributing

Add a prompt when you have one that actually worked, not a theory.

## File format

```markdown
# Short title

One-line description of when to use it.

## Prompt

    (fenced text block with the prompt)

## How to use

- What to paste in the placeholders
- Expected output
```

## Rules

- One prompt per file.
- Placeholders in `[SQUARE_BRACKETS]`.
- No secrets, no personal data, no jailbreaks.
- Put it in the closest folder (`coding/`, `writing/`, `learning/`, `filipino/`, `grok/`, `meta/`).
- Update the table in `README.md` if you add a new folder.
